## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Event Frequency** | Adjust how often different helicopter events spawn in your game |
| **Event Types** | Enable or disable specific helicopter event categories |
| **Noise Radius** | Set how far each event type attracts zombies |
| **Time Restrictions** | Limit certain events to day or night only spawns |
